# Classic Companion 試用版

版本 {{VERSION}}，建置 {{BUILD}}。

**這是試用版，不是正式穩定版，驗收仍有未決事項。**

Classic Companion 以原生 macOS 視窗開啟 ChatGPT 官方網頁。按 `⌥Space` 叫出。小視窗和完整視窗顯示的是同一個官方頁面，只是大小不同，用 `⌃⌘F` 切換。兩個快速鍵都可以在 設定 → 快速鍵 中更改。

非 OpenAI 官方 App，與 OpenAI 沒有關聯。

## 系統需求和測試範圍

- 最低系統需求：macOS 15.0 或以上版本，只支援 Apple 晶片（arm64）。不支援搭載 Intel 處理器的 Mac。
- 已驗證：一台搭載 Apple M4 Max 的 MacBook Pro，macOS 27.2（用 DMG 安裝、第一次打開、四種介面語言和主要功能）。
- 尚未驗證：macOS 15、macOS 26；其他 Mac 和全新的使用者環境；用 ZIP 安裝；部分實體按鍵和輸入法操作只做過工具驅動的測試；App 內更新尚未在正式更新位址上實際收到過更新；叫出時的視窗模式在 VoiceOver 下的朗讀，以及在較小的螢幕上叫出、視窗需要縮小的情況。

## 安裝

用 DMG 安裝：
1. 按兩下下載的 DMG 打開它。
2. 在打開的視窗中，把 `Classic Companion` 拖到「應用程式」檔案夾。
3. 在「應用程式」中按兩下打開，然後登入 ChatGPT 帳號。之後可以退出 DMG。

用 ZIP 安裝：
1. 下載 ZIP。瀏覽器可能已經自動解壓縮；如果沒有，在「Finder」中按兩下 ZIP，得到 `Classic Companion`。
2. 先把它拖到「應用程式」檔案夾，再打開。
3. 在「應用程式」中按兩下打開，然後登入 ChatGPT 帳號。

兩種方式都不需要使用「終端機」。

本版使用 Developer ID 簽署，並經過 Apple 公證。第一次打開時，macOS 可能會要求安全確認，確認是 Classic Companion 後選擇打開即可。如果 macOS 提示無法打開，請不要更改系統的安全設定，可以到 Issues 回饋。

## 更新

- 從 0.1.0-beta.2 起可以在 App 內更新：在 Classic Companion 選單中選擇「檢查更新項目⋯」，或在 設定 → 一般 → 更新 中打開「自動檢查更新項目」（第二次打開 App 時也會詢問一次）。在更新視窗中選擇安裝後，會先請你確認「下載並安裝」：確認之前不會下載或安裝任何東西，也不會在結束時自動安裝；確認後，下載並驗證一完成，Classic Companion 就會自動結束、安裝並重新打開，不再詢問。
- 更新完成後重新打開時，會回到上次的對話（設定 → 一般 中的「啟動時重新打開最近瀏覽的對話」，預設為開啟），但不會回到原本的捲動位置；一般結束後再打開也一樣。用叫出快速鍵、關閉按鈕或 `⌘W` 隱藏再叫出視窗時，閱讀位置不變。在測試機上用單獨的測試副本從 0.1.0-beta.2 在 App 內更新到本版時（使用本機的測試更新來源），登入狀態、未傳送的草稿和設定都保留了。
- **0.1.0-beta.1（建置 20261110.0137）沒有更新功能，不會提示有新版本。** 正在使用它的話，請依照上面的「安裝」步驟手動安裝本版一次，取代「應用程式」中的舊版；登入狀態和設定會保留。之後的版本可以在 App 內更新。
- 檢查、下載和發生錯誤時的更新視窗使用 macOS 的語言，不跟隨 App 中選擇的介面語言；「下載並安裝」的確認視窗跟隨 App 介面語言。

## 使用

- App 語言：App 介面有简体中文、繁體中文、English、日本語四種，預設跟隨 macOS 的偏好語言（都不符合時使用英文），可以在 設定 → 一般 → App 語言 中更改，立即生效。這只影響 App 自己的介面，不會改變 ChatGPT 網頁的語言；網頁語言請在 ChatGPT 自己的設定中更改。macOS 提供的選單項目和對話框跟隨系統語言。
- 設定分為三頁：一般（App 語言、頁面縮放、叫出時的視窗模式、啟動時重新打開對話、叫出後將游標放在輸入框、Esc 隱藏視窗、自動檢查更新項目）、快速鍵、進階（網頁增強功能、允許其他 App 讀取網頁內容、診斷）。
- App 會顯示在 Dock 和 `⌘Tab` 中，選單列也有圖像。按一下 Dock 圖像、用 `⌘Tab` 切換或再次打開 App，都會找回原本的視窗，不會重新載入頁面。
- 關閉按鈕和 `⌘W` 只會隱藏視窗，App 繼續執行。按 `⌘Q` 才會結束。
- 按叫出快速鍵（預設 `⌥Space`）時使用哪種視窗，在 設定 → 一般 → 叫出時的視窗模式 中選擇：預設為「保持上次的模式」，隱藏時是完整視窗，就以完整視窗回來；選「一律使用小視窗」時每次都以小視窗出現（0.1.0-beta.2 及更早版本的做法）。按一下 Dock 圖像、用 `⌘Tab` 切換或再次打開 App 時保持目前的模式，不受這一項影響；啟動 App 時仍然是小視窗。
- 叫出快速鍵預設為 `⌥Space`。按 `⌘,` 或從選單列圖像打開設定，在「快速鍵」中按一下欄位後按下想用的組合。其他 App 也在使用的組合也能錄製，但之後按下時可能會觸發那個 App，也可能讓這裡的快速鍵無法使用。錄製時如果看到其他 App 打開了視窗，設定中會以橙色顯示它的名稱，建議換一個組合，或在那個 App 中更改它的快速鍵。小視窗和完整視窗的切換快速鍵預設為 `⌃⌘F`，也在「快速鍵」中更改，只在本 App 的視窗位於最前方時有效。
- 視窗頂部左邊的 ✕ 會隱藏視窗，右邊兩個按鈕是新增對話和切換小視窗／完整視窗。拖移頂部空白處可以移動視窗，按兩下頂部空白處可在小視窗和完整視窗之間切換（如果在系統設定中把按兩下標題列設為縮到最小，則會縮到最小）。淺色、深色外觀跟隨 ChatGPT 自己的主題設定。
- 網頁增強功能開啟時（預設開啟，在 設定 → 進階），小視窗會隱藏 ChatGPT 頁首自己的「打開側邊欄」和「新增聊天」兩個按鈕，頂部右邊的新增按鈕和 `⌘N` 照常可用。這要依靠官方網頁的結構：網頁改版後，或把小視窗拉寬、把頁面縮小而讓網頁改用寬版排版時，這兩個按鈕可能會出現。其他內容和網頁版相同，側邊欄、歷史紀錄和搜尋中的最近對話仍可能出現在小視窗中（例如用 ChatGPT 自己的快速鍵打開側邊欄、用 `⌘K` 搜尋），分享螢幕時請留意。
- `⌘+`、`⌘-`、`⌘0` 調整頁面大小，文字和頁面一起縮放，也可以在 設定 → 一般 → 頁面縮放 中選擇。完整視窗會記住你調整後的大小。
- 朗讀：使用回答下方的 ChatGPT 官方朗讀按鈕。目前只支援開始和停止；不支援暫停、繼續或調整速度，停止後再次開始不保證從中斷處繼續。

## 已知問題

1. 關閉圖片預覽後，縮圖可能空白，尚未確認修正。
2. 互動元件未驗證，對話中的這類元件可能顯示或操作異常。
3. 朗讀中重新產生回答時，舊的朗讀可能繼續播放，需要按一下官方停止按鈕或結束 App。朗讀時切換對話、切換分支、用 `⌥Space` 隱藏視窗的行為未驗證。
4. 長對話快速向上捲動時偶爾回彈。Safari 中表現相近，本版不修正。
5. 在其他 App 的全螢幕畫面上叫出視窗，只在雙顯示器下測試過，單一顯示器未測試。
6. 在小視窗中編輯已傳送的訊息時，編輯框可能跑到可見範圍上方，要往上捲動一點才看得到。Safari 視窗窄時也一樣，視窗寬時則不會，屬於官方頁面的行為，本版不修正。
7. 按 `⌘M` 後再次打開 App（不是按一下 Dock），視窗偶爾停在 Dock 圖像處，沒有展開。結束 App 後再打開可以恢復。原因尚未查明。
8. 在系統語言為英文的測試機上，各介面語言下「編輯」選單的「還原／重做」都顯示為 Undo / Redo；介面為中文或日文時，「顯示方式」選單中沒有「進入全螢幕」等項目。這是在測試機上觀察到的行為，原因待查。
9. 在偏好語言為英文、日文、簡體中文的測試機上手動選擇繁體中文時，App 原生介面中的標點會以簡體中文或日文的字形顯示（例如「，」「。」位於左下而非置中）。這是在測試機上觀察到的行為，原因尚未確認。

## 回饋

請到 GitHub Issues 回饋：https://github.com/xtymac/ClassicCompanion/issues

在「關於 Classic Companion」中可以拷貝版本資訊，診斷視窗（設定 → 進階 → 打開診斷）可以拷貝已去除敏感資訊的報告，回報問題時連同問題描述一起附上。Issues 是公開的，請勿貼上對話內容、帳號資訊或截圖中的私人內容。

## 回復到舊版本

回復前請先看要回復的那個版本附帶的試用版說明，按照那一版寫的方法安裝和使用；不同版本的介面語言、圖像和選單可能不一樣。

1. 按 `⌘Q` 結束 App。
2. 從「應用程式」刪除目前的 `Classic Companion`。
3. 用目標版本的 DMG 或 ZIP，按照那一版的說明把 App 放進「應用程式」，然後打開。

登入狀態存放在 App 之外，替換 App 時不會刪除。不保證任意兩個版本之間來回切換都相容：新版本改過的設定，舊版本可能無法辨識或顯示不同。回復後遇到問題，請到 Issues 回饋。

## 解除安裝

結束 App 後刪除它，並刪除下列位置。刪除第 1、2 項後需要重新登入。

1. `~/Library/WebKit/local.classiccompanion.ClassicCompanion`
2. `~/Library/HTTPStorages/local.classiccompanion.ClassicCompanion.binarycookies`
3. `~/Library/Application Support/ClassicCompanion`（本機診斷紀錄）
4. `~/Library/Caches/local.classiccompanion.ClassicCompanion`
5. `~/Library/Preferences/local.classiccompanion.ClassicCompanion.plist`
