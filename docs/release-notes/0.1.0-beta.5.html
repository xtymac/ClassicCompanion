What’s new

  • Tabs: open up to 4 chats in one window. Press ⌘T or click + on the tab bar for a new tab. New Chat (⌘N or the button at the top right) now also opens in a new tab, or in the current tab when 4 are already open. ⌘-click a chat link to open it in a background tab, and switch tabs with ⌃Tab or ⌘1–⌘4. With 2 or more tabs, ⌘W closes the current tab, and ✕ hides the window and keeps the tabs.
  • Back and Forward: use ⌘[ and ⌘], the mouse side buttons, or the File menu. On pages that aren’t chats, such as the pricing page or a shared link, a Back arrow appears next to ✕ when you can go back.
  • File → Restart Audio: something to try when Read Aloud has no sound after the audio output device changes. It doesn’t reload the page. Whether it restores sound in that case hasn’t been verified yet.

Improvements

  • In the context menu of an image in an answer, Download Image and Open Image in New Window now work: the image is saved to your Downloads folder, or opens in its own window instead of a blank one. Copy Image now also works for SVG images. The image window shows only the picture: links and embedded content inside an SVG do nothing.
  • If you turn on automatic update checks when the app asks, and that first check finds a new version, the Download and Install window now appears instead of the update only being marked in the menus.
  • Closing a sign-in pop-up window now closes it fully; it no longer keeps running in the background.

Known limitations: each tab is a full ChatGPT page and uses about 700 MB of memory (measured on one Mac). Restart Audio stops the sound in every tab, not only the current one. Tabs aren’t kept after you quit. See the Beta Notes for other known issues.

新功能

  • 标签页：一个窗口里最多开 4 个对话。按 ⌘T 或点标签栏上的 + 新建标签页。新建对话（⌘N 或右上角的按钮）现在也开在新标签页里，已经开了 4 个时在当前标签页里新建。按住 ⌘ 点聊天链接，会在后台的新标签页里打开；用 ⌃Tab 或 ⌘1–⌘4 切换标签页。开着 2 个或更多标签页时，⌘W 关闭当前标签页，✕ 隐藏窗口、标签页都保留。
  • 后退和前进：用 ⌘[ 和 ⌘]、鼠标侧键或文件菜单。在不是聊天的页面上（例如定价页或分享链接），可以后退时 ✕ 旁会出现“后退”箭头。
  • 文件 → 重启音频：切换音频输出设备后朗读没有声音时可以试试，不会重新加载页面。这个操作能否恢复声音，仍待验证。

改进

  • 回答里的图片，右键菜单中的下载和在新窗口中打开现在都能用了：图片存到“下载”文件夹，或在单独的窗口里打开，不再是空白窗口。SVG 图片现在也能拷贝。图片窗口只显示图片本身：SVG 里的链接和内嵌内容不起作用。
  • 应用询问是否自动检查更新时，如果你选择打开，而这第一次检查就发现了新版本，现在会显示“下载并安装”窗口，不再只在菜单里标出。
  • 关闭登录弹窗后，它会完全关掉，不再留在后台运行。

已知限制：每个标签页都是一个完整的 ChatGPT 页面，内存占用约 700 MB（在一台 Mac 上测得）。“重启音频”会让所有标签页的声音都停止，不只是当前标签页。退出应用后标签页不保留。其他已知问题见试用版说明。

新功能

  • 分頁：一個視窗中最多開 4 個對話。按 ⌘T 或按一下分頁列上的 + 新增分頁。新增對話（⌘N 或右上角的按鈕）現在也會開在新分頁中，已經開了 4 個時在目前的分頁中新增。按住 ⌘ 按一下聊天連結，會在背景的新分頁中打開；用 ⌃Tab 或 ⌘1–⌘4 切換分頁。開著 2 個或更多分頁時，⌘W 關閉目前的分頁，✕ 隱藏視窗、分頁都會保留。
  • 上一頁和下一頁：用 ⌘[ 和 ⌘]、滑鼠側鍵或「檔案」選單。在不是聊天的頁面上（例如價格頁面或分享連結），可以回到上一頁時 ✕ 旁會出現「上一頁」箭頭。
  • 檔案 → 重新啟動音訊：切換音訊輸出裝置後朗讀沒有聲音時可以試試，不會重新載入頁面。這個操作能否恢復聲音，仍待驗證。

改進

  • 回答中的圖片，右鍵選單中的下載和在新視窗中打開現在都能使用了：圖片會存到「下載項目」檔案夾，或在單獨的視窗中打開，不再是空白視窗。SVG 圖片現在也能拷貝。圖片視窗只顯示圖片本身：SVG 裡的連結和內嵌內容不會作用。
  • App 詢問是否自動檢查更新項目時，如果你選擇打開，而這第一次檢查就發現了新版本，現在會顯示「下載並安裝」視窗，不再只在選單中標示。
  • 關閉登入彈出視窗後，它會完全關閉，不再留在背景執行。

已知限制：每個分頁都是一個完整的 ChatGPT 頁面，記憶體用量約 700 MB（在一台 Mac 上測得）。「重新啟動音訊」會讓所有分頁的聲音都停止，不只是目前的分頁。結束 App 後分頁不會保留。其他已知問題請見試用版說明。

新機能

  • タブ：1 つのウインドウで最大 4 つのチャットを開けます。⌘T を押すか、タブバーの + をクリックすると新規タブを開きます。新規チャット（⌘N または右上のボタン）も新しいタブで開くようになりました。すでに 4 つ開いているときは今のタブで新規チャットになります。チャットのリンクを ⌘ クリックするとバックグラウンドのタブで開き、⌃Tab や ⌘1〜⌘4 でタブを切り替えられます。タブが 2 つ以上のときは ⌘W で今のタブを閉じ、✕ でタブを残したままウインドウを隠します。
  • 戻る / 進む：⌘[ と ⌘]、マウスのサイドボタン、またはファイルメニューを使います。料金ページや共有リンクなど、チャット以外のページで戻れるときは、✕ の横に「戻る」矢印が表示されます。
  • ファイル →「オーディオを再起動」：音声出力デバイスを切り替えたあとに読み上げの音が出ないときに試せます。ページは読み込み直されません。この操作で音が出るようになるかどうかは、まだ検証していません。

改善

  • 回答内の画像のコンテキストメニューで、ダウンロードと新規ウインドウで開く操作が使えるようになりました。画像は「ダウンロード」フォルダに保存されるか、専用のウインドウで開きます（以前は空白のウインドウでした）。SVG 画像もコピーできるようになりました。画像ウインドウには画像だけが表示され、SVG 内のリンクや埋め込みコンテンツは動作しません。
  • アプリが自動アップデート確認について尋ねたときにオンにし、その最初の確認で新しいバージョンが見つかった場合は、メニューに印が付くだけでなく「ダウンロードしてインストール」のウインドウが表示されるようになりました。
  • ログインのポップアップウインドウを閉じると完全に閉じるようになり、バックグラウンドで動き続けることはなくなりました。

既知の制限：タブはそれぞれが完全な ChatGPT のページで、1 つあたり約 700 MB のメモリを使います（1 台の Mac で測定）。「オーディオを再起動」を使うと、今のタブだけでなくすべてのタブの音が止まります。アプリを終了するとタブは残りません。そのほかの既知の問題は「ベータ版の説明」を参照してください。
