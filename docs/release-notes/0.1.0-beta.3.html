What’s new

  • New setting: Settings → General → Window Mode When Shown. With Keep Last Mode, the default, the show/hide shortcut brings the window back in the mode it was hidden in, so a Full window comes back as a Full window. Choose Always Quick Window to keep the earlier behavior.
  • Clicking the Dock icon, ⌘Tab and opening the app again keep the current mode as before, and the app still starts in the Quick window.

新功能

  • 新设置：设置 → 通用 → 唤醒时窗口模式。默认保持上次模式：按唤醒快捷键时，窗口以隐藏时的模式回来，完整窗口就以完整窗口回来。选总是小窗可保持以前的做法。
  • 点 Dock 图标、⌘Tab 和再次打开应用时照旧保持当前模式；启动应用时仍然是小窗。

新功能

  • 新設定：設定 → 一般 → 叫出時的視窗模式。預設為保持上次的模式：按叫出快速鍵時，視窗以隱藏時的模式回來，完整視窗就以完整視窗回來。選擇一律使用小視窗可保持以前的做法。
  • 按一下 Dock 圖像、用 ⌘Tab 切換和再次打開 App 時照舊保持目前的模式；啟動 App 時仍然是小視窗。

新機能

  • 新しい設定：設定 →「一般」→表示時のウインドウモード。最初は前回のモードのままで、表示 / 非表示のショートカットを押すと、隠したときのモードで戻ります（フルウインドウはフルウインドウのまま）。以前と同じ動作にするには常にクイックを選んでください。
  • Dock のアイコン、⌘Tab、アプリをもう一度開いたときは今までどおり今のモードのままで、起動時はクイックウインドウです。
