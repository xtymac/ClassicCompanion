What’s new

  • New app icon: a graphite-gray companion with a small lightning bolt, so the app is easier to pick out in the Dock and in ⌘Tab.
  • The top of the window now shows a lightning bolt and “Classic Companion” next to the ✕ button, so the window is easier to tell apart from other chat apps. They are not buttons: you can still drag the window or double-click there.

Nothing else changes in how the app works. See the Beta Notes for known issues.

新功能

  • 新的应用图标：石墨灰的团子加一个小闪电，在 Dock 和 ⌘Tab 里更容易认出来。
  • 窗口顶部的 ✕ 按钮旁边现在显示闪电和“Classic Companion”，更容易和别的聊天应用的窗口区分。它们不是按钮：在那里仍然可以拖动窗口或双击。

应用的其他用法没有变化。已知问题见试用版说明。
