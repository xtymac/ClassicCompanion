What’s new

  • The new graphite-gray app icon has a small lightning bolt on its chest. Look for it in the Dock or when switching apps with ⌘Tab.
  • The top of the window now shows a lightning bolt and “Classic Companion” next to the ✕ button, so the window is easier to tell apart from other chat apps. You can still drag or double-click this area.

Nothing else changes in how the app works. See the Beta Notes for known issues.

新功能

  • 新的应用图标：石墨灰的团子加一个小闪电，在 Dock 和 ⌘Tab 里更容易认出来。
  • 窗口顶部的 ✕ 按钮旁边现在显示闪电和“Classic Companion”，更容易和别的聊天应用的窗口区分。在标识上仍然可以拖动窗口或双击。

应用的其他用法没有变化。已知问题见试用版说明。

新功能

  • 新的 App 圖像是胸前帶著小閃電的石墨灰糰子。在 Dock 裡或按 ⌘Tab 切換 App 時，都更容易認出它。
  • 視窗上方的 ✕ 按鈕旁新增了閃電圖像和「Classic Companion」字樣，方便辨認視窗。在這個區域一樣可以拖移視窗或按兩下。

App 的其他用法沒有變化。已知問題請見試用版說明。

新機能

  • アプリアイコンが新しくなりました。胸に小さな稲妻をあしらったグラファイトグレーのキャラクターが、Dock や ⌘Tab でアプリを切り替えるときの目印です。
