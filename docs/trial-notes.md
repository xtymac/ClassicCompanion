# Classic Companion 试用版

版本 {{VERSION}}，构建 {{BUILD}}。

**这是试用版，不是正式稳定版，验收仍有未决项。**

Classic Companion 用原生 macOS 窗口打开 ChatGPT 官方网页。按 `⌥Space` 唤出。小窗和完整窗口显示的是同一个官方页面，只是大小不同，用 `⌃⌘F` 切换。两个快捷键都可以在 设置 → 快捷键 里改。

非 OpenAI 官方应用，与 OpenAI 没有关联。

## 系统要求和测试范围

- 最低系统要求：macOS 15.0 或更新版本，只支持 Apple 芯片（arm64），不支持 Intel Mac。
- 已验证：一台搭载 Apple M4 Max 的 MacBook Pro，macOS 27.2（用 DMG 安装、第一次打开、四种界面语言和主要功能）。
- 未验证：macOS 15、macOS 26；其他 Mac 和全新的用户环境；用 ZIP 安装；部分实体按键和输入法操作只做过工具驱动的测试；应用内更新还没有在正式更新地址上实际收到过更新；唤醒时窗口模式在 VoiceOver 下的朗读，以及在更小的屏幕上唤醒、窗口需要缩小的情况。

## 安装

用 DMG 安装：
1. 双击下载的 DMG 打开它。
2. 在打开的窗口里，把 `Classic Companion` 拖到“应用程序”文件夹。
3. 在“应用程序”里双击打开，然后登录 ChatGPT 账号。之后可以推出 DMG。

用 ZIP 安装：
1. 下载 ZIP。浏览器可能已经自动解压；没有的话，在“访达”里双击 ZIP，得到 `Classic Companion`。
2. 先把它拖到“应用程序”文件夹，再打开。
3. 在“应用程序”里双击打开，然后登录 ChatGPT 账号。

两种方式都不需要打开终端。

本版使用 Developer ID 签名，并经过 Apple 公证。第一次打开时，macOS 可能会弹出安全确认，确认是 Classic Companion 后选择打开即可。如果 macOS 提示无法打开，请不要更改系统的安全设置，可以到 Issues 反馈。

## 更新

- 从 0.1.0-beta.2 起可以在应用内更新：在 Classic Companion 菜单里选择“检查更新…”，或在 设置 → 通用 → 更新 里打开“自动检查更新”（第二次打开应用时也会询问一次）。在更新窗口里选择安装后，会先请你确认“下载并安装”：确认之前不会下载或安装任何东西，也不会在退出时自动安装；确认后，下载和验证一完成，Classic Companion 就会自动退出、安装并重新打开，不再询问。
- 更新完成后重新打开时，会回到上次的对话（设置 → 通用 里的“启动时恢复最近访问的对话”，默认开着），但不会回到原来的滚动位置；普通退出再打开也一样。用唤醒键、关闭按钮或 `⌘W` 隐藏再唤醒窗口时，阅读位置不变。在测试机上用单独的测试副本从 0.1.0-beta.2 应用内更新到本版时（用本机的测试更新源），登录状态、未发送的草稿和设置都保留了。
- **0.1.0-beta.1（构建 20261110.0137）没有更新功能，不会提示有新版本。** 正在用它的话，请按上面的“安装”步骤手动安装本版一次，替换“应用程序”里的旧版；登录状态和设置会保留。之后的版本可以在应用内更新。
- 检查、下载和出错时的更新窗口使用 macOS 的语言，不跟随应用里选的界面语言；“下载并安装”的确认窗口跟随应用界面语言。

## 使用

- 界面语言：应用界面有简体中文、繁體中文、English、日本語四种，默认跟随 macOS 的首选语言（都对不上时用英文），可以在 设置 → 通用 → 应用语言 里改，立即生效。这只影响应用自己的界面，不改变 ChatGPT 网页的语言；网页语言在 ChatGPT 自己的设置里改。macOS 提供的菜单项和对话框跟随系统语言。
- 设置分三页：通用（应用语言、页面缩放、唤醒时窗口模式、启动时恢复对话、唤醒后聚焦输入框、Esc 隐藏窗口、自动检查更新）、快捷键、高级（网页增强、允许其他应用读取网页内容、诊断）。
- 应用会显示在 Dock 和 `⌘Tab` 中，菜单栏也有图标。点 Dock 图标、`⌘Tab` 切入或再次打开应用，都会找回原来的窗口，不会重新加载页面。
- 关闭按钮和 `⌘W` 只隐藏窗口，应用继续运行。`⌘Q` 才退出。
- 按唤醒键（默认 `⌥Space`）时用哪种窗口，在 设置 → 通用 → 唤醒时窗口模式 里选：默认“保持上次模式”，隐藏时是完整窗口，就以完整窗口回来；选“总是小窗”时每次都以小窗出现（0.1.0-beta.2 及更早版本的做法）。点 Dock 图标、`⌘Tab` 或再次打开应用时保持当前模式，不受这一项影响；启动应用时仍然是小窗。
- 唤醒键默认是 `⌥Space`。按 `⌘,` 或从菜单栏图标打开设置，在“快捷键”里点框后按下想用的组合。别的应用也在用的组合也能录进来，但之后按下时可能会触发那个应用，也可能让这里的快捷键不起作用。录的时候如果看到别的应用开了窗口，设置里会用橙色写出它的名字，最好换一个组合，或在那个应用里改掉它的快捷键。小窗和完整窗口的切换键默认是 `⌃⌘F`，也在“快捷键”里改，它只在本应用窗口在前台时有效。
- 窗口顶部左边的 ✕ 隐藏窗口，右边两个按钮是新建对话和切换小窗 / 完整窗口。拖动顶部空白处可以移动窗口，双击顶部空白处在小窗和完整窗口之间切换（系统设置里把连按标题栏改成最小化时就最小化）。浅色、深色跟随 ChatGPT 自己的主题设置。
- 网页增强开着时（默认开着，在 设置 → 高级），小窗会隐藏 ChatGPT 页头自己的“打开侧栏”和“新建对话”两个按钮，顶部右边的新建按钮和 `⌘N` 照常可用。这要靠官方网页的结构：网页改版后，或者把小窗拉宽、把页面缩小后网页换成宽版排版时，这两个按钮可能会出现。其他内容和网页版一样，侧栏、历史记录和搜索里的最近会话仍可能出现在小窗里（例如用 ChatGPT 自己的快捷键打开侧栏、`⌘K` 搜索），共享屏幕时请留意。
- `⌘+`、`⌘-`、`⌘0` 调整页面大小，文字和页面一起缩放，也可以在 设置 → 通用 → 页面缩放 里选。完整窗口会记住你调整后的大小。
- 朗读：使用回答下方的 ChatGPT 官方朗读按钮。目前只支持开始和停止；不支持暂停、继续或调速，停止后再次开始不保证从中断处继续。

## 已知问题

1. 图片预览关闭后，缩略图可能空白，尚未确认修复。
2. 交互组件未验证，对话里的这类组件可能显示或操作异常。
3. 朗读中重新生成时，旧朗读可能继续播放，需要点官方停止按钮或退出应用。朗读时切换对话、切换分支、用 `⌥Space` 隐藏窗口的行为未验证。
4. 长对话快速向上滚动时偶尔回弹。Safari 里表现相近，本版不修。
5. 在其他应用的全屏界面上唤醒窗口，只在双显示器下测试过，单显示器未测试。
6. 在小窗里编辑已发送的消息时，编辑框可能跑到视野上方，要往上滚一点才能看到。Safari 窗口窄时也一样，窗口宽时没有，属官方页面的表现，本版不修。
7. 按 `⌘M` 后再次打开应用（不是点 Dock），窗口偶尔停在 Dock 图标处，没有展开。退出应用再打开可以恢复。原因尚未查明。
8. 在系统语言为英文的测试机上，各界面语言下编辑菜单的“撤销 / 重做”都显示为 Undo / Redo；界面为中文或日文时，“显示”菜单里没有“进入全屏幕”等项目。这是在测试机上观察到的现象，原因待查。
9. 在首选语言为英文、日文、简体中文的测试机上手动选择繁體中文时，应用原生界面里的标点按简体中文或日文的字形显示（例如“，”“。”在左下而不是居中）。这是在测试机上观察到的现象，原因尚未确认。

## 反馈

请到 GitHub Issues 反馈：https://github.com/xtymac/ClassicCompanion/issues

在“关于 Classic Companion”里可以复制版本信息，诊断窗口（设置 → 高级 → 打开诊断）可以复制脱敏报告，提问题时和问题描述一起附上。Issues 是公开的，不要贴对话内容、账号信息或截图里的私人内容。

## 回退到旧版本

回退前先看要回退的那个版本附带的试用版说明，按那一版写的方法安装和使用；不同版本的界面语言、图标和菜单可能不一样。

1. 按 `⌘Q` 退出应用。
2. 从“应用程序”删除当前的 `Classic Companion`。
3. 用目标版本的 DMG 或 ZIP，按那一版的说明把应用放进“应用程序”，然后打开。

登录状态存放在应用之外，替换应用时不会删除。不保证任意两个版本之间来回切换都兼容：新版本改过的设置，旧版本可能不认识或显示不同。回退后遇到问题，请到 Issues 反馈。

## 卸载

退出应用后删除它，并删除下列位置。删除第 1、2 项后需要重新登录。

1. `~/Library/WebKit/local.classiccompanion.ClassicCompanion`
2. `~/Library/HTTPStorages/local.classiccompanion.ClassicCompanion.binarycookies`
3. `~/Library/Application Support/ClassicCompanion`（本地诊断记录）
4. `~/Library/Caches/local.classiccompanion.ClassicCompanion`
5. `~/Library/Preferences/local.classiccompanion.ClassicCompanion.plist`
