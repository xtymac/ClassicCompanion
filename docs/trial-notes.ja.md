# Classic Companion ベータ版

バージョン {{VERSION}}、ビルド {{BUILD}}。

**これはベータ版で、安定版ではありません。確認が終わっていない項目があります。**

Classic Companion は、ChatGPT の公式 Web サイトをネイティブの macOS ウインドウで開きます。`⌥Space` で呼び出します。クイックウインドウとフルウインドウは同じ公式ページを大きさを変えて表示するもので、`⌃⌘F` で切り替えます。どちらのショートカットも 設定 → ショートカット で変更できます。

OpenAI の公式アプリではなく、OpenAI とは提携していません。

## 動作環境と確認範囲

- 最低動作環境：macOS 15.0 以降、Apple シリコン（arm64）のみ。Intel プロセッサ搭載の Mac には対応していません。
- 確認済み：Apple M4 Max 搭載の MacBook Pro 1 台、macOS 27.2（DMG からのインストール、初回起動、4 つの画面言語、主な機能）。
- 未確認：macOS 15、macOS 26、ほかの Mac や新しいユーザ環境、ZIP からのインストール。一部の物理キーと入力メソッドの操作は、ツールによる入力でのみ確認しています。

## インストール

DMG からインストールする場合：
1. ダウンロードした DMG をダブルクリックして開きます。
2. 開いたウインドウで、`Classic Companion` を「アプリケーション」フォルダにドラッグします。
3. 「アプリケーション」でダブルクリックして開き、ChatGPT アカウントにログインします。そのあと DMG は取り出して構いません。

ZIP からインストールする場合：
1. ZIP をダウンロードします。ブラウザが自動で展開することがあります。展開されていない場合は、Finder で ZIP をダブルクリックすると `Classic Companion` が現れます。
2. 開く前に、「アプリケーション」フォルダにドラッグします。
3. 「アプリケーション」でダブルクリックして開き、ChatGPT アカウントにログインします。

どちらの場合もターミナルは必要ありません。

このビルドは Developer ID で署名され、Apple の公証を受けています。初めて開くとき、macOS が確認を求めることがあります。Classic Companion であることを確かめてから開いてください。開けないと表示された場合は、Mac のセキュリティ設定を変更せず、Issues でお知らせください。

## 使い方

- アプリの言語：アプリの画面は簡体字中国語、繁体字中国語、英語、日本語に対応しています。最初は macOS の優先する言語に合わせ（どれにも当てはまらないときは英語）、設定 → 一般 → アプリの言語 で変更できます。変更はすぐに反映されます。変わるのはこのアプリ自身の画面だけで、ChatGPT の Web ページの言語は変わりません（ChatGPT 側の設定で変更してください）。macOS が用意するメニュー項目やダイアログは macOS の言語で表示されます。
- 設定は 3 つのページに分かれています：一般（アプリの言語、ページの拡大/縮小、最後のチャットの再表示、入力欄へのカーソル、Esc で隠す）、ショートカット、詳細（Web 補助機能、ほかのアプリによる Web ページの読み取り、診断）。
- アプリは Dock と `⌘Tab` に表示され、メニューバーにもアイコンがあります。Dock のアイコンをクリックする、`⌘Tab` で切り替える、アプリをもう一度開く、のどれでも元のウインドウが戻り、ページは再読み込みされません。
- 閉じるボタンと `⌘W` はウインドウを隠すだけで、アプリは動き続けます。終了は `⌘Q` です。
- 呼び出しのショートカットは最初は `⌥Space` です。`⌘,` またはメニューバーのアイコンから設定を開き、「ショートカット」で枠をクリックしてから使いたい組み合わせを押します。ほかのアプリが使っている組み合わせも記録できますが、押したときにそのアプリが反応したり、このアプリのショートカットが効かなくなったりすることがあります。記録中にほかのアプリがウインドウを開いた場合は、設定にそのアプリ名がオレンジ色で表示されます。別の組み合わせにするか、そのアプリ側でショートカットを変更することをおすすめします。クイック / フルウインドウの切り替えは最初は `⌃⌘F` で、これも「ショートカット」で変更できます。このアプリのウインドウが最前面にあるときだけ使えます。
- ウインドウ上部の左の ✕ でウインドウを隠し、右の 2 つのボタンで新規チャットとクイック / フルウインドウの切り替えができます。上部の空いている部分をドラッグするとウインドウを移動でき、ダブルクリックするとクイックとフルウインドウが切り替わります（システム設定でタイトルバーのダブルクリックを「しまう」にしている場合はしまいます）。ライト / ダークの外観は ChatGPT 自身のテーマ設定に従います。
- Web 補助機能がオンのとき（初期設定はオン、設定 → 詳細）、クイックウインドウではページ上部にある ChatGPT 自身の「サイドバーを開く」と「新しいチャット」のボタンを隠します。右上の新規チャットボタンと `⌘N` はそのまま使えます。これは公式ページの構造に依存しているため、ページが更新されたときや、クイックウインドウを広げたりページを縮小したりしてページが広い画面用のレイアウトになったときは、これらのボタンが表示されることがあります。そのほかは Web 版と同じで、サイドバー、履歴、検索の最近のチャットがクイックウインドウに表示されることがあります（ChatGPT 自身のショートカットでサイドバーを開いたり、`⌘K` で検索したりしたときなど）。画面共有中はご注意ください。
- `⌘+`、`⌘-`、`⌘0` でページの大きさを変えられ、文字とページが一緒に拡大 / 縮小されます。設定 → 一般 → ページの拡大/縮小 でも選べます。フルウインドウは調整したサイズを記憶します。
- 読み上げ：回答の下にある ChatGPT 公式の読み上げボタンを使ってください。現在は開始と停止のみに対応しています。一時停止、再開、速度の変更には対応しておらず、停止後にもう一度開始しても中断した位置から再開されるとは限りません。

## 既知の問題

1. 画像のプレビューを閉じたあと、サムネールが空白になることがあります。修正はまだ確認できていません。
2. インタラクティブなコンポーネントは確認しておらず、チャット内で正しく表示・操作できないことがあります。
3. 読み上げ中に回答を再生成すると、前の読み上げが続くことがあります。ChatGPT の停止ボタンを押すか、アプリを終了してください。読み上げ中にチャットやブランチを切り替えたり、`⌥Space` でウインドウを隠したりしたときの動作は確認していません。
4. 長いチャットで素早く上にスクロールすると、ときどき跳ね返ります。Safari でも同様のため、このビルドでは修正しません。
5. ほかのアプリのフルスクリーン表示の上でウインドウを呼び出す操作は、ディスプレイ 2 台の環境でのみ確認しています。1 台の環境では確認していません。
6. クイックウインドウで送信済みのメッセージを編集すると、編集欄が表示範囲の上に隠れることがあります。少し上にスクロールすると見えます。Safari でもウインドウが狭いと同じで、広いと起きないため、公式ページの動作です。このビルドでは修正しません。
7. `⌘M` のあとにアプリをもう一度開くと（Dock をクリックした場合を除く）、ウインドウが Dock のアイコンの位置で止まり、広がらないことがあります。アプリを終了して開き直すと元に戻ります。原因はまだ分かっていません。
8. システムの言語が英語のテスト機では、アプリの言語にかかわらず編集メニューの「取り消す／やり直す」が Undo / Redo と表示され、アプリが中国語か日本語のときは「表示」メニューに「フルスクリーンにする」などの項目がありません。テスト機で観察された動作で、原因は未確認です。
9. 優先する言語が英語・日本語・簡体字中国語のテスト機で繁体字中国語を手動で選ぶと、アプリのネイティブ画面の句読点が簡体字中国語または日本語の字形で表示されます（たとえば「，」「。」が中央ではなく左下に寄ります）。テスト機で観察された動作で、原因は未確認です。

## 以前のバージョンに戻す

戻す前に、戻したいバージョンに付いているベータ版の説明を読み、その説明に従ってください。画面の言語、アイコン、メニューはバージョンによって異なることがあります。

1. `⌘Q` でアプリを終了します。
2. 「アプリケーション」から現在の `Classic Companion` を削除します。
3. 戻したいバージョンの DMG または ZIP を使い、その説明のとおりにアプリを「アプリケーション」に入れて開きます。

ログイン状態はアプリの外に保存されているため、アプリを入れ替えても削除されません。どのバージョン間でも行き来できるとは限りません。新しいバージョンで変更した設定を、以前のバージョンが認識しなかったり、違う表示になったりすることがあります。戻したあとに問題が起きた場合は、Issues でお知らせください。

## アンインストール

アプリを終了して削除し、次の場所も削除します。1 と 2 を削除すると、もう一度ログインが必要です。

1. `~/Library/WebKit/local.classiccompanion.ClassicCompanion`
2. `~/Library/HTTPStorages/local.classiccompanion.ClassicCompanion.binarycookies`
3. `~/Library/Application Support/ClassicCompanion`（ローカルの診断記録）
4. `~/Library/Caches/local.classiccompanion.ClassicCompanion`
5. `~/Library/Preferences/local.classiccompanion.ClassicCompanion.plist`
