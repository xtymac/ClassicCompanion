# App icon resources

`AppIcon.icns` is copied unchanged into the app bundle. `AppIcon-1024.png` is its PNG reference. `STATUS` marks the application icon as final. The menu bar uses separate monochrome template images: `MenuBarIconTemplate.png` and `MenuBarIconTemplate@2x.png` are a solid lightning bolt (18×18 and 36×36, transparent background) that macOS tints for light and dark menu bars. Unpackaged runs use the system symbol `bolt.fill`.
