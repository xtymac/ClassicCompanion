# README images

Images and the short video shown in the READMEs, kept here so they do not depend on organization-hosted URLs. They are excluded from the root Apache-2.0 license (see BRANDING.md).

- `poster-en.png`, `poster-ja.png`, `poster-zh-hans.png`, `poster-zh-hant.png`: top posters, refreshed for 0.1.0-beta.5 (current app icon and window top bar). Same layout and copy as the earlier posters.
- `tabs-demo.gif`, `tabs-demo.mp4`: tab demo (about 12 seconds, no sound). Two recordings joined with one cut; opening the second chat in the new tab is not shown.
- `companion-settings.png`: settings screenshot, unchanged.

The window captures are real and unedited. They were taken with an ad-hoc debug build of the `v0.1.0-beta.5` source that runs under a separate bundle identifier, not with the notarized download. The background, headline, shortcut keys, the outline around the tab bar and the caption strip were added afterwards. Sample chats are fictional.
