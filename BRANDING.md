# Branding and included assets

The source code, documentation (excluding promotional images in `assets/marketing/`) and included app/menu icons are provided under Apache-2.0. This allows compiling, modifying and redistributing the included assets with the application under that license.

Apache-2.0 does not grant trademark rights. The names MacTokyo and Classic Companion and their branding must not be used to imply that an independently modified distribution is an official release or endorsed by the maintainers. We recommend a distinct app name, icon and bundle identifier for independent distributions. This note does not add restrictions to the copyright permissions in Apache-2.0.

ChatGPT and OpenAI names identify the service the app uses; no rights in those brands or the service's content are granted. The official website and user conversations are not included in this repository. Private design drafts are not included. Previously published promotional images are stored in `assets/marketing/` for README display. Those images are excluded from the Apache-2.0 source license; moving them here does not change their existing rights. See `assets/marketing/README.md`.
